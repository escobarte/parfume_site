SITEMAP И СТРУКТУРА РОУТИНГА
1. Основная навигация (Main Flow)

/ — Главная страница (Home). Отсюда ведут ссылки на категории, карточки популярных товаров, информационные страницы и личный кабинет.

/catalog — Общий каталог товаров.

/catalog/[category-name] — Страница категории (например, /catalog/men, /catalog/women, /catalog/niche). Отсюда пользователь переходит в конкретный товар.

/product/[product-id] — Страница товара (PDP). Сюда можно попасть с Главной, из Каталога, из Поиска, из Избранного или из Корзины.

2. Процесс покупки (Checkout Flow)

/cart — Корзина. Сюда пользователь попадает по клику на иконку корзины в шапке или после добавления товара (если не используется всплывающее окно-minicart). Из корзины идет переход на оформление.

/checkout — Оформление заказа. Страница с формой данных покупателя.

/thank-you — Страница благодарности (успешное оформление заказа). Показывается после отправки формы в /checkout.

3. Пользовательский раздел (User Account Flow)

/login и /register — Авторизация и Регистрация.

/account — Личный кабинет. (Доступно только авторизованным). Содержит подразделы:

/account/orders — История заказов.

/account/bonuses — Бонусный счет.

/wishlist — Избранное. Страница с отложенными товарами. Сюда можно попасть из шапки сайта.

/compare — Сравнение товаров. Таблица сравнения характеристик.

4. Информационные страницы (Static Pages)

/about — О магазине.

/payment — Оплата.

/delivery — Доставка.

/contacts — Контакты.

/blog — Блог со статьями.

/blog/[article-id] — Страница конкретной статьи.

Логика основных переходов (User Flow):

Покупка: Главная -> Категория -> Страница товара (выбор объема) -> Корзина -> Оформление заказа -> Спасибо за заказ.

Быстрая покупка: Главная / Категория -> Клик "Купить в 1 клик" на карточке товара -> Модальное окно -> Отправка формы.

Поиск: Ввод в строку поиска в Header -> Выпадающий список (Live Search) -> Клик на товар -> Страница товара.»
