# Бриф дизайнеру — MON FLACON (каталог парфюмерии, Молдова)

Проект: интернет-каталог парфюмерии MON FLACON (сайт-визитка с каталогом и заявками, без онлайн-оплаты). Технологическая база уже готова (Next.js + Payload CMS, три локали ro/ru/en), нужны макеты страниц и вайрфреймы на основе утверждённого брендбука.

**Брендбук уже согласован и разобран в `docs/BRAND.md`** (источник — «MON FLACON — Концепция брендинга», PDF 2026) — палитра Deep Navy `#16293D` / Warm Cream `#E8CFB0`, типографика, паттерн, фотостиль, голос бренда. Просьба опираться на него при разработке макетов, а не создавать айдентику заново. Ключевые выдержки ниже — полный файл доступен по запросу.

## 0. Из брендбука — коротко

- **Палитра:** Deep Navy `#16293D` (доминанта — шапка/футер/hero/промо), Warm Cream `#E8CFB0` (акцент — лого, ховеры, плашки), белый/тёплый нейтральный (`#FFFFFF` / `#F6F0E4`) — контентные зоны каталога.
- **Типографика:** Helvetica Neue в брендбуке → веб-замена Inter (латиница + кириллица + румынские диакритики ș ț ă â î). Заголовки — UPPERCASE, увеличенный трекинг, лёгкое начертание, много воздуха.
- **Графика:** тонкие линии-разделители вместо теней/рамок; радиусы минимальные (0–4px); композиция — воздух, формула промо-блока «1 image + 1 phrase + logo».
- **Голос:** спокойный, личный, без рекламного давления; фирменные EN-фразы (*Find your signature.* и т.п.) не переводятся.

## 1. Что нужно передать (токены)

Figma-файл с явно поименованными токенами:
- **Палитра:** 4–6 именованных цветов с hex (на основе navy/cream из BRAND.md §2 — финальное распределение navy-«рамы» и светлых поверхностей уточняется по вашим вайрфреймам).
- **Типографика:** display + body (+ отдельная utility-роль для цен/числовых данных) — шкала размеров и веса (300/400/500 согласно BRAND.md §3).
- **Отступы:** шкала спейсинга.
- **Радиусы:** согласно BRAND.md §5 — минимальные (0–4px).
- **Тени:** если используются — но по языку бренда предпочтительны линии, не elevation.

## 2. Брейкпоинты

360 / 768 / 1280 (1536 — опционально, desktop-wide).

## 3. Экраны

1. Главная (hero, категории, подборки товаров, промо-блоки).
2. Листинг каталога с открытыми фильтрами — десктоп-версия и мобильный bottom-sheet.
3. Карточка товара — **приоритетно, см. п.8**.
4. Корзина.
5. Форма заявки + страница «спасибо».
6. Страница бренда.
7. Статическая страница (о нас / доставка / возврат / контакты — единый шаблон).
8. 404.

## 4. Состояния компонентов

Для интерактивных элементов: hover / focus / active / disabled / error / loading / empty (отдельно — пустая корзина, пустой результат поиска).

## 5. Три локали — проверка на длинных строках

Макеты должны выдерживать реальную длину текста: RU и RO в среднем **до ~30% длиннее EN**. Проверить заголовки, кнопки, лейблы фильтров — ничего не должно обрезаться/ломать сетку.

## 6. Шрифты

Обязательна поддержка **latin + cyrillic** (кириллица — критично для RU-локали) и румынских диакритиков (ș ț ă â î) для RO. Нужна лицензия для web. Дефолтное решение по брендбуку — **Inter** (бесплатный, полное покрытие); альтернатива — покупка веб-лицензии Helvetica Neue (решение фиксируется с клиентом, см. BRAND.md §3).

## 7. Ассеты

- **Иконки и логотип — в SVG.** По BRAND.md §4/§9 нужны: полная версия логотипа, знак отдельно (favicon/компактная шапка), инверсии (для navy/cream/светлого фона), favicon-набор, графический паттерн (BRAND.md §5) в SVG. Не перерисовывать логотип — только оригинальные исходники.
- **Фотостайлгайд для карточек товара** (фон, отступы, соотношение сторон 1:1 или 4:5, ≥1200px по длинной стороне) — по нему клиент будет готовить 100+ фото товаров. Ориентир по свету/фактурам/тону — BRAND.md §6.

## 8. Приоритет — карточка товара в листинге

Компонент карточки товара нужен **отдельно и в первую очередь** — это ~80% визуала сайта (десятки повторений на листинге). Включает: изображение, бренд, название, диапазон цен, флаги (новинка/акция/нет в наличии), hover-состояние.

## 9. Открытые вопросы к дизайнеру (из BRAND.md §9)

1. SVG-исходники логотипа/знака/инверсий/паттерна/favicon — от вас.
2. Итоговое решение по шрифту (Inter или лицензия Helvetica Neue) — уточняется с клиентом, но если есть мнение по вёрстке — welcome.
3. Финальный цвет ошибок форм и статусов заказов в админке — вне брендбука, предложение в BRAND.md §2 (`#B3453C`), можно скорректировать.
4. Структура сайта и вайрфреймы (карта разделов) — первичный вход для макетов; если есть готовое видение структуры — присылайте прямо с макетами.

## 10. Формат и срок

Готовые макеты — Figma-ссылка с доступом на комментирование. Дедлайн фиксируется отдельно с владельцем проекта и должен укладываться до начала фазы 6 (интеграция дизайна, ориентировочно 3-я неделя разработки) — до этого момента фронтенд разрабатывается на нейтральных токенах, дизайн встраивается без блокировки остальной разработки.
