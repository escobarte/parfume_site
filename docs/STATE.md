## Проект в двух строках

Сайт-каталог парфюмерии **MON FLACON** для рынка **Молдовы**. Витрина без онлайн-оплаты: карточки товаров, фильтры, корзина, форма заявки. ~100+ товаров × 5–7 объёмов → модель `Product → Variants` (~600 SKU). Локали **RO / RU / EN**, валюта **MDL**. Сборку делает **Claude Code** (терминал WSL), чат claude.ai — штаб: планирует, разбирает ошибки, готовит документы клиенту. Проект локально: `~/projects/parfume_site`.

**Сессия 2026-08-22/23 — боевой тест импорта на проде и что он за собой потянул.** Начиналось как пункт 3 из четырёх ручных действий («прогнать CSV через кнопку в админке»), но живой тест на реальных данных вскрыл цепочку вещей, которых не было в плане. Все они сделаны, смержены в `phase_8.0`, задеплоены и **владельцем на проде проверены**:

1. **Модель данных: `title` товара больше не `localized`** (миграция `20260822_140412_phase8_1_title_not_localized.ts`). Разведка перед миграцией показала: у 12/12 демо-товаров title был **дословно одинаков** во всех трёх локалях — «перевод» названий через `demo-translations.csv` был фиктивным дублированием, реально переводилось только описание. По уточнению у клиента: **названия товаров всегда на английском, одни на все языки; переводится только описание.** Бэкфилл автоматический (первая непустая локаль ro→ru→en), ручные FTS/trigram-индексы поиска перенесены внутри той же миграции (`migrate:create` их не видит — грабля записана в GOTCHAS). Колонка `title` убрана из формата CSV-переводов (`handle,locale,description`).
2. **Мультиязычные описания одним файлом.** Форматы A/B понимают колонки `description_ro` / `description_ru` / `description_en` — все три языка за один прогон, селектор «Локаль контента» на такой файл не влияет. Одиночная `description` осталась для обратной совместимости.
3. **Загрузка фото товаров ZIP-архивом** (`/api/media-import`, блок «Шаг 1» на `/admin/catalog-import`) + привязка колонкой `images` в CSV по точному имени файла. Два независимых действия, не одна кнопка: сначала архив, потом CSV. Распаковка в памяти (`adm-zip`, чистый JS), файл в Media заводится штатным `payload.create({file: Buffer})` без записи на диск. Лимиты 200 МБ/архив, 8 МБ/файл. Ненайденное имя — предупреждение в отчёте, импорт не прерывается. Непустая ячейка `images` заменяет список фото целиком, пустая — не трогает.

## Как обновлять этот файл

В конце сессии, если закрыта фаза/подфаза, изменился список «Ждёт владельца», сместился план или появился новый блокер:

1. Правится **только раздел «Где мы», «Что дальше» и «Ждёт владельца»** — остальное статично.
2. Дата в шапке — обязательно.
3. Файл сохраняется в репозиторий **и** перезаливается в файлы проекта claude.ai (одна и та же версия в двух местах, имя не меняется — никаких `-4`, `-5`).
