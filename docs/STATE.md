## Проект в двух строках

Сайт-каталог парфюмерии **MON FLACON** для рынка **Молдовы**. Витрина без онлайн-оплаты: карточки товаров, фильтры, корзина, форма заявки. ~100+ товаров × 5–7 объёмов → модель `Product → Variants` (~600 SKU). Локали **RO / RU / EN**, валюта **MDL**. Сборку делает **Claude Code** (терминал WSL), чат claude.ai — штаб: планирует, разбирает ошибки, готовит документы клиенту. Проект локально: `~/projects/parfume_site`.

## Организационный контекст

- **Хранилище фото:** диск VPS (persistent volume `/app/media` в Coolify), S3/R2 — потом, если понадобится (переключается адаптером Payload).
- **Email заявок:** Resend, ключ на проде пока не заполнен (`RESEND_API_KEY` — см. «Ждёт владельца» выше). Письмо менеджеру (фаза 4) и клиенту (4.6) написаны, домен и Cloudflare DNS уже есть — можно верифицировать отправителя и подставить боевой ключ в любой момент.
- **Telegram:** работает боевым и на деве, и на проде (проверено на деве вживую в фазе 4; на проде `ORDERS_DRY_RUN=0` — заявки реально уходят, боевая проверка через ручную приёмку, см. «Ждёт владельца»). Бот `@mooflaco_order_bot`, `TELEGRAM_CHAT_ID=799511005`, токен в `.env` на деве и в env-переменных Coolify на проде.
- **Регистрация / личные кабинеты:** не нужны, только гостевой заказ. Отслеживание — по токену или номер+телефон, без ЛК.
- **Оплата:** онлайн нет. Позже — Paynet или эквайринг maib / Victoriabank. Stripe в Молдове недоступен.
- **Документы клиенту** (у владельца, не в репо): презентация v7 (docx + pdf), чек-лист v3 (docx + pdf). Цена проекта — **1 200 €** единоразово, поддержка 2 месяца включена.

## Как обновлять этот файл

В конце сессии, если закрыта фаза/подфаза, изменился список «Ждёт владельца», сместился план или появился новый блокер:
