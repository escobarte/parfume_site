# WIREFRAMES.md — структура и композиция страниц

Зафиксированные вайрфреймы MON FLACON. Источник визуальной правды — референс-мокапы в `docs/mockups/` (открываются в браузере). Этот файл описывает структуру, поведение и привязку к данным. Приоритет при конфликте: **WIREFRAMES.md + мокап → BRAND.md → PLAN.md**. Файл пополняется по мере утверждения остальных страниц.

Статус: ✅ Главная (утверждена, мокап `docs/mockups/home.html`) · ⏳ Каталог · ⏳ Карточка товара · ⏳ Корзина/заявка · ⏳ Страница бренда · ⏳ Статика.

---

## Глобальные решения (действуют на всех страницах)

1. **Navy — рама, контент — светлый.** `#16293D` занимает шапку, hero, editorial-блоки и футер. Контентные зоны — белый `#FFFFFF` и тёплый `#F6F0E4`. Тёмных контентных зон нет.
2. Разделение — только 1px линиями (`#E3DACA` на светлом, `rgba(232,207,176,.2–.25)` на navy). Теней нет нигде.
3. Заголовки секций и кнопки — uppercase, вес 300, letter-spacing 0.14–0.22em. Названия товаров — вес 500, обычный регистр.
4. Ховеры: смена цвета границы/фона (карточка → navy-бордер; кнопка-outline → заливка cream с текстом navy). Без transform, без теней.
5. Стрелки в ссылках — типографские тонкие (`→` / иконка ti-arrow-right), в конце ссылки.
6. Фирменные EN-фразы (Find your signature. / A scent for every story. / Scents that feel like you. / Perfumes for everyone) — не переводятся, служат заголовками-акцентами.

## Промо-баннер (глобальный, опциональный)

- Узкая полоса **над** шапкой на всех страницах, если включена в global `settings.promoBanner` и системная дата попадает в её `startDate`–`endDate` (обе границы необязательны — отсутствующая не ограничивает). Не найдена активной — блок не рендерится вовсе, места не занимает.
- Высота 34–38px, фон `#E8CFB0` (cream), текст `#16293D` (navy) — единственное место на сайте, где cream выступает фоном контентной зоны, а не акцентом на navy; допустимо, т.к. это тонкая служебная полоса, не контентная зона.
- Текст uppercase, tracking .14em, локализован. Опциональная ссылка внутри текста — тем же navy, подчёркнута 1px. Крестик закрытия справа, 16px, navy.
- **Ссылка — выбор из списка внутренних целей, не свободный текст** (отменяет прежнее «URL ссылки» произвольным текстовым полем — оно давало 404 на опечатках слага): Главная / Каталог / Каталог со скидками / Бренды / О нас / Доставка / Контакты, плюс необязательное поле «своя ссылка» — если заполнено, побеждает выбор из списка (для внешних URL). Код резолвит выбранную цель в локализованный путь. Часть целей (Бренды, О нас, Доставка, Контакты) — страницы фазы 5, до их появления это ожидаемо 404. В фазе 5 (коллекция Pages) select апгрейдится до relationship-поля.
- Закрытие запоминается на сессию (не навсегда): в новой вкладке/сессии баннер снова виден, если ещё активен по датам.
- Обычный блок в потоке документа, не sticky — шапка остаётся `sticky top-0` под ним и получает управление после того, как баннер уходит при скролле; sticky-сжатие шапки не завязано на баннер и работает одинаково с ним и без него.

## Шапка (глобальная)

- Фон navy, нижняя граница 1px cream 25%.
- Слева: знак (SVG из брендбука) + MON FLACON (tracking .3em, 300) + дескриптор PERFUMES FOR EVERYONE (9–10px, muted `#8FA0B2`).
- Центр: навигация — Каталог · Бренды · Новинки · О нас (uppercase 12px, cream, tracking .14em).
- Справа: иконка поиска → раскрывает строку поиска с автодополнением; переключатель локалей `RO · RU · EN` (активная — cream с подчёркиванием 1px, остальные `#7488A0`); корзина (иконка сумки) с бейджем-кружком cream, цифра navy.
- Sticky при скролле: шапка сжимается, полный логотип → только знак (правило брендбука о малых форматах).
- Мобильная (<768): знак + бургер (ti-menu-2) + корзина; навигация и локали — в выезжающем меню.

## Главная — порядок секций

`Шапка → Hero → Лента категорий → Новинки → Editorial-блок → Бренд-строка → [опц. слот: второй товарный ряд «Хиты»] → Футер`

### 1. Hero (navy)

- Композиция центрированная, вертикальные отступы ~88/96px (desktop).
- Слои фона: 1–2 гигантских знака флакона (SVG), обрезанных краями экрана, cream при opacity 0.05–0.06 — это фирменный паттерн, не декорация поверх текста.
- Контент сверху вниз: eyebrow `PERFUMES FOR EVERYONE` (11px, tracking .22em, `#8FA0B2`) → H1 `FIND YOUR SIGNATURE.` (uppercase, 300, tracking .14em, cream, ~40px desktop / ~26–28px mobile) → hairline 44px cream 45% → подстрока 1–2 строки (14.5px, 300, `#B9C4CF`, локализована; RU-версия: «Современная парфюмерная галерея в Кишинёве. Аромат — личный выбор: исследуйте, пробуйте, находите своё.») → CTA-кнопка outline cream «ОТКРЫТЬ КАТАЛОГ» → `/[locale]/catalog`.
- **Слайдера нет — hero-подмена по датам, без слайдера** (отменяет прежнюю формулировку «один статичный hero», зафиксировано в фазе 4.5). Обычный режим — статичный hero, управляется из global `homepage` (заголовок-фраза, подстрока, ссылка CTA). Опционально поверх него включается **акционная версия** (`homepage.promoHero`, тоже global `homepage`): пока она включена и системная дата попадает в её `startDate`–`endDate`, hero **целиком** рендерится в акционной версии вместо обычной — та же композиция/отступы/типографика этого раздела, другой контент и, если задана, фоновая картинка (с navy-оверлеем поверх, чтобы cream-текст держал контраст AAA). Вне интервала или при выключенной акции — обычный hero, переключение автоматическое. Один экран одновременно: **не карусель, не ротация, не автосмена** — выбор версии решается на сервере по системным часам при каждом запросе, hero остаётся полностью server-rendered.
- **CTA акционной версии — тот же select+override, что у промо-баннера** (единообразие): цель из списка внутренних страниц (в т.ч. «Каталог со скидками» — готовый ярлык на отфильтрованный каталог) или своя ссылка override. Апгрейд до Pages-relationship — вместе с баннером, в фазе 5. CTA обычного hero (не акционного) свободным текстовым полем не тронут — вне вопроса этой правки.

### 2. Лента категорий (тёплая поверхность `#F6F0E4`)

- 4 равные плитки в ряд, разделены 1px `#E3DACA`, без внешних отступов секции.
- Плитка: название uppercase 12.5px navy + счётчик «N ароматов» (11.5px, `#4A5A6B`). Счётчики — живые, из БД.
- Состав: Она / Он / Унисекс / Наборы (маппинг на категории CMS; состав редактируем из global).
- Ховер: фон плитки → белый. Мобильная: сетка 2×2.

### 3. Новинки (белый)

- Шапка секции: слева «НОВИНКИ» (15px uppercase navy), справа ссылка «СМОТРЕТЬ ВСЕ →» (12px, `#4A5A6B`) → каталог с фильтром isNew.
- Сетка карточек: 4 колонки ≥1280, 3 на 1024–1279, 2 на мобиле. Данные: товары с флагом `isNew`, limit по сетке.
- **Карточка товара (эталон для всего сайта):**
  - фото-зона: тёплый фон `#F6F0E4`, высота ~190px, флакон по центру (фотостиль BRAND §6);
  - рамка 1px `#E3DACA`, radius 0–2px, hover → рамка `#16293D`;
  - бренд: 10.5px uppercase tracking .2em `#4A5A6B`;
  - название: 14.5px, вес 500, navy;
  - строка семейства/нот: 12px `#4A5A6B` («древесный · сандал, кедр»);
  - чипы объёмов из variants: 11px, рамка 1px, «5 ml · 10 ml · 30 ml»;
  - цена: «от {minPrice} MDL», 14px, вес 500, navy;
  - **плашка наличия** — в одной строке с ценой, справа: 10.5px uppercase, трекинг .2em, как бренд в шапке карточки. Источник — `product.inStock` (хук денормализации по вариантам). В наличии — `#4A5A6B`; нет в наличии — приглушённее, `#9AA6B4`. Это текст, а не подложка: ни фона, ни тени, ни рамки. Строки локализованы: RO «În stoc» / «Stoc epuizat», RU «В наличии» / «Нет в наличии», EN «In stock» / «Out of stock».
  - **бейдж скидки** (фаза 4.5) — правый верхний угол фото-зоны, отступ 9–12px от края; заливка `#16293D` (navy), текст `#E8CFB0` (cream), формат «−30%», мелкий uppercase, трекинг .14em, radius минимальный (как у карточки), без тени и рамки. **Вариант B (отменяет прежнюю формулировку «максимум среди активных вариантов» с ценой отдельно от бейджа):** бейдж и цена карточки всегда об одном и том же варианте. Если у товара есть уценённые варианты (`oldPrice > price`), карточка находит среди них тот, у которого процент скидки максимален, и показывает целиком его — его цену как «от N MDL» (даже если это не минимальный объём товара), его же зачёркнутую `oldPrice` рядом и бейдж его процента. Нет уценённых вариантов — нет ни бейджа, ни зачёркивания, обычная минимальная цена. **Инвариант: бейдж без зачёркнутой цены рядом невозможен, и наоборот.**
  - Вся карточка — ссылка на товар.

> Карточка едина для всего сайта: любое изменение в ней (включая плашку наличия и бейдж скидки) автоматически действует во всех товарных сетках — каталог, категория, результаты поиска, «похожие» на странице товара, ряды «Новинки»/«Хиты» на главной.
>
> **Фильтр и сортировка по скидке** (фаза 4.5): фасет по `hasDiscount` со счётчиком — та же генерическая механика, что у `isNew`/`isHit`; в UI подписан как **Sale** (во всех локалях). Ручного тега `isSale` («Акция» отдельной биркой, как New/Bestseller) в модели больше нет — убран целиком (путал рядом с авто-фасетом «со скидкой»); единственный источник «скидочности» — денормализованный `hasDiscount`. Сортировка «по размеру скидки» — по `maxDiscountPercent` по убыванию, в общем списке сортировок каталога.

### 4. Editorial-блок (navy, формула «1 image + 1 phrase + logo»)

- Двухколоночный grid 1.4fr / 1fr, без зазора, колонки на всю высоту блока.
- Левая (navy): фраза `A SCENT FOR EVERY STORY.` (uppercase 300, ~22px, tracking .16em, cream) → hairline 36px → предложение 13.5px `#B9C4CF` → текст-ссылка «ГИД ПО АРОМАТАМ →» (cream, tracking .18em).
- Правая: плита cream во всю высоту с крупным знаком navy по центру. Когда появится editorial-фотография по фотостилю — знак заменяется фото, плита остаётся.
- Мобильная: колонки в стек, текст сверху.
- Контент из global `homepage`.

### 5. Бренд-строка (белый)

- Одна центрированная строка: названия брендов uppercase 12px, tracking .26em, `#9AA6B4`, разделитель « · ». Без логотипов.
- Список брендов — из global `homepage` (выбор «featured»), каждый — ссылка на страницу бренда. Нижняя граница секции 1px.

### 6. Футер (navy)

- 4 колонки (1.3fr / 1fr / 1fr / 1.1fr): ① знак + MON FLACON + фраза «Scents that feel like you.» (11.5px, `#7488A0`); ② Каталог: Новинки, Бренды, Она, Он; ③ Покупателям: Доставка, Оплата, Возврат, Контакты; ④ Контакты: адрес, телефон, мессенджеры (из global `settings`).
- Ссылки: 12.5px, `#B9C4CF`, hover → cream. Заголовки колонок uppercase 11px cream.
- Разделитель над нижней строкой 1px cream 20%. Нижняя строка: «© {год} MON FLACON · Perfumes for everyone» слева; «RO · RU · EN   MDL» справа (локали кликабельны).
- Мобильная: колонки 2×2 → 1.

### Опциональный слот

Между editorial и бренд-строкой зарезервировано место под второй товарный ряд («Хиты» по флагу isHit) — та же сетка и карточки, что «Новинки». Включается из global `homepage`, в мокапе отсутствует намеренно.

## Привязка к данным (сводно)

| Секция | Источник |
|---|---|
| Hero (фраза, подстрока, CTA) | global `homepage`, localized |
| Акционный hero (подмена по датам) | global `homepage.promoHero`, localized |
| Промо-баннер над шапкой | global `settings.promoBanner`, localized |
| Категории + счётчики | коллекция `categories` + live counts |
| Новинки / Хиты | `products` по флагам, сортировка по дате |
| Бейдж скидки, фильтр «со скидкой» | `products.hasDiscount` / `maxDiscountPercent` (денормализация) |
| Editorial (фраза, текст, ссылка, изображение) | global `homepage`, localized |
| Бренд-строка | global `homepage` → relationship `brands` |
| Футер: меню | global `navigation` |
| Футер: контакты, адрес, мессенджеры | global `settings` |

## Открытое (появится со следующими вайрфреймами)

Каталог (фильтры/сетка), карточка товара, корзина и форма заявки, страница бренда, статика, 404. До их утверждения Claude Code строит эти страницы по PLAN.md + BRAND.md, перенося паттерны главной: карточку товара из §3, navy-раму, линии, типографику.
