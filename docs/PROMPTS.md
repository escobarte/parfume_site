# PROMPTS.md — плейбук промптов для Claude Code

Рабочая последовательность проекта. Каждый блок в рамке — **готовый промпт**: копируешь целиком в Claude Code. Всё остальное он делает и проверяет сам (правила — в `CLAUDE.md`), ведёт `docs/CHANGELOG.md` и в конце выдаёт **⎇ git-блок** — ты его вставляешь в терминал, это и есть твой git.

**Твоя работа на весь проект:** вставлять промпты → вставлять git-блоки → заполнять короткие клик-листы (аккаунты/оплаты, которые физически нельзя автоматизировать) → изредка смотреть глазами (👁).

Файлы в репозитории: `CLAUDE.md` — корень; `PLAN.md`, `PROMPTS.md` — в `docs/`.

## ШАГ 0 — Бутстрап руками (единственный ручной блок, ~20 минут, один раз)

До первого промпта Claude Code должен существовать. Только это делается вручную.

**Docker — нативно внутри Ubuntu (без Docker Desktop):**
```bash
# 1. Включить systemd, чтобы демон Docker стартовал сам
sudo tee /etc/wsl.conf > /dev/null << 'EOF'
[boot]
systemd=true
EOF
```
Затем в PowerShell: `wsl --shutdown`, открыть Ubuntu заново и продолжить:
```bash
# 2. docker-ce + compose-плагин по официальной инструкции docs.docker.com/engine/install/ubuntu
#    (блок из ~6 команд: репозиторий Docker + apt install docker-ce docker-compose-plugin)
# 3. Работа без sudo:
sudo usermod -aG docker $USER && newgrp docker
# 4. Проверка:
docker run hello-world && docker compose version
```

**В WSL Ubuntu (инструменты):**
```bash
# nvm — одной curl-командой из README github.com/nvm-sh/nvm, затем:
nvm install 22 && corepack enable
git config --global core.autocrlf input
git config --global init.defaultBranch main
mkdir -p ~/projects/parfum && cd ~/projects/parfum && git init
```

**Claude Code:** установка внутри WSL по официальной инструкции https://code.claude.com/docs/en/setup (нативный установщик; альтернатива — `npm install -g @anthropic-ai/claude-code`). Затем `claude` → логин (план Pro/Max или ключ Console) → `claude doctor` — всё зелёное.

**GitHub:** создать приватный репозиторий в браузере (пустой), привязать:
```bash
ssh-keygen -t ed25519    # если ключа нет; .pub добавить в GitHub → Settings → SSH keys
git remote add origin git@github.com:ТВОЙ_ЛОГИН/ИМЯ_РЕПО.git
```

Положить в папку проекта три файла: `CLAUDE.md` (корень), `docs/PLAN.md`, `docs/PROMPTS.md`. Готово — дальше только промпты.

> Если `next build` когда-нибудь упадёт по памяти (OOM): WSL по умолчанию берёт 50% RAM. Лечится файлом `C:\Users\<user>\.wslconfig` → `[wsl2]` `memory=10GB`, `swap=8GB` + `wsl --shutdown`. До проблемы — не трогать.
