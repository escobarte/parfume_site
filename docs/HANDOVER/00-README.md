## Что это за система

**MON FLACON** — сайт-каталог парфюмерии для Молдовы (`monflacon.md`). Три языка (румынский по умолчанию, русский, английский), цены в леях (MDL). Онлайн-оплаты и личных кабинетов нет: покупатель собирает корзину и отправляет **заявку**, менеджер связывается и оформляет продажу вручную. Заявка сохраняется в базе и одновременно уходит в Telegram, на почту менеджера (с CSV и PDF), покупателю (если он оставил email) и файлом на сервер для 1С.

Технически это **одно приложение Next.js 16 + Payload CMS 3** в одном Docker-контейнере: Next отдаёт витрину, Payload — админку `/admin`, REST/GraphQL и доступ к данным. База — PostgreSQL 17. Хостинг — VPS с Coolify за Cloudflare. Фото хранятся на диске сервера. Бэкапы — в Backblaze B2.

Каталог: товар → варианты (объём из 5 фиксированных значений, цена, остаток), бренды, ноты, разделы «Для неё / Для него / Детям / Body Care / Skin Care», подарочные сертификаты и Gift Box, промокоды двух типов, кампании скидок. Наполнение — вручную в админке или CSV-импортом.

## Словарь

| Термин | Что значит в этом проекте |
|---|---|
| **Payload** | CMS, встроенная в Next: даёт админку `/admin`, схему данных (коллекции и глобалы), REST/GraphQL и Local API |
| **Коллекция / глобал** | таблица однотипных записей (товары, заявки) / одна запись-настройка (главная, настройки сайта, меню, попап) |
| **Local API** | вызов Payload из кода напрямую (`payload.find(...)`), без HTTP; по умолчанию без проверки прав |
| **Хук** | функция Payload, срабатывающая при сохранении/удалении записи (пересчёт цен, сброс кэша) |
| **Денормализация** | поля товара `minPrice`, `maxPrice`, `inStock`, `hasDiscount`, `maxDiscountPercent`, которые хук считает из вариантов; руками не пишутся |
| **Вариант** | строка товара с объёмом, артикулом (`sku`), ценой, старой ценой, остатком |
| **`handle`** | код товара из прайса магазина — ключ CSV-импорта |
| **slug** | часть адреса страницы латиницей, одна на все языки |
| **Coolify** | панель на VPS, которая собирает Docker-образ из GitHub, держит контейнеры, домены, SSL и бэкапы БД |
| **Traefik** | обратный прокси внутри Coolify (TLS, маршрутизация доменов) |
| **no-staging** | отдельного тестового сервера нет: каждый деплой идёт сразу на прод |
| **Заглушка (stub, maintenance)** | режим «сайт в разработке»: `MAINTENANCE_MODE=1` закрывает витрину страницей-заглушкой; вход по секретной ссылке `?preview=` |
| **Байпас** | секретная ссылка `?preview=<токен>`, ставящая cookie `mf_preview` для входа при заглушке |
| **Кэш витрины** | сохранённые результаты запросов к БД (`unstable_cache`), сбрасываются хуками и кнопкой «Сбросить кэш витрины» |
| **Формат A / B** | товарный CSV: A — строка = вариант; B — варианты одной JSON-колонкой |
| **«Лёгкий прайс»** | CSV из колонок `sku, price, stock` — обновление только цен и остатков, для регулярной выгрузки из 1С |
| **Dry-run / пробный режим** | проверка CSV без записи в базу |
| **`needsReview`** | флажок ноты «заготовка, не проверена»; ставится автоматически на ноты, созданные импортом |
| **Промокод personal / public** | персональный (`WELCOME-…`, из попапа, одноразовый, привязан к email и телефону) / публичный (для соцсетей, многоразовый, со сроком) |
| **Попап «первая скидка»** | всплывающее окно, выдающее персональный промокод |
| **Кампания скидок** | массовая ручная уценка выбранных товаров кнопками «Запустить» / «Остановить» с журналом для отката |
| **Раздел (section)** | закрытая выдача левого меню (For Her, For Him, Kids, Body Care, Skin Care) — задаётся маршрутом, не фильтром |
| **`ORDERS_DRY_RUN`** | `1` — заявки создаются, но Telegram и письма не отправляются |
| **`statusToken`** | случайный ключ публичной страницы статуса заказа `/order/<token>` |
| **Restore-drill** | учебное восстановление из бэкапа (`docs/restore-drill.md`) |
