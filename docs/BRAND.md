# BRAND.md — дизайн-система MON FLACON для веба

Источник: «MON FLACON — Концепция брендинга» (PDF, 2026). Здесь — извлечённые из брендбука правила, адаптированные под веб. Claude Code применяет этот файл во всех UI-задачах с фазы 1. Приоритет при конфликте: вайрфреймы/макеты страниц → этот файл → общие дефолты (и при конфликте этот файл обновляется).

## 1. Бренд в двух строках

**MON FLACON · Perfumes for everyone.** Современная парфюмерная галерея для широкой аудитории: визуально утончённая, спокойная и премиальная — но без холодной недоступности и чрезмерной роскоши. Аромат — личный выбор, а не демонстрация статуса. Принцип всей системы: **less, but more meaningful** — минимализм это не отсутствие деталей, а точный выбор деталей.

## 2. Палитра

| Токен | HEX | Роль |
|---|---|---|
| `--color-navy` | `#16293D` | Deep Navy — главный цвет: шапка, футер, hero, промо-блоки, кнопки, текст на светлом |
| `--color-cream` | `#E8CFB0` | Warm Cream — акцент: лого и текст на тёмном, плашки, линии, ховеры |
| `--color-surface` | `#FFFFFF` | базовая поверхность контентных зон |
| `--color-surface-warm` | `#F6F0E4` *(производный)* | тёплый нейтральный фон секций |

Иерархия из брендбука: navy — доминанта, cream — вторичный, белый/нейтральный — вспомогательный. Металлическое золото **не** обязательный цвет — вместо него матовое кремовое тонирование.

**Веб-прочтение тёмной доминанты.** Брендбук задаёт navy основным фоном — для витрины с плотным каталогом применяем его как «раму»: шапка, футер, hero, editorial- и промо-блоки, бейджи. Контентные зоны каталога и карточек — светлые тёплые поверхности (читаемость и плотность важнее). Ощущение бренда сохраняется на ключевых экранах. Финальное распределение — по вайрфреймам.

**Контраст (проверено):** cream на navy ≈ 9.8:1 — AAA, можно текст любого размера. Navy на cream/белом — отлично. Cream на белом — **только декоративно**, текстом никогда.

**Вне брендбука (согласовать):** цвет ошибок форм — предлагается приглушённый терракотово-красный `#B3453C`; статусные цвета заказов в админке.

## 3. Типографика

Брендбук: **Helvetica Neue** (Light / Regular / Medium) — главный голос системы.

> ⚠️ **Лицензия.** Helvetica Neue не бесплатна для веба (Monotype, платная webfont-лицензия). Решение по умолчанию: **Inter** (variable) — ближайший свободный гротеск с полной кириллицей **и румынскими диакритиками ș ț ă â î** (критично для RO-локали). Веса 300/400/500 ≈ Light/Regular/Medium. Если клиент купит лицензию Helvetica Neue — замена одним токеном `--font-sans`, вёрстка не меняется. Решение зафиксировать с клиентом до фазы 6.

Правила из брендбука → в вёрстку:
- **Заголовки:** UPPERCASE, увеличенный трекинг (`letter-spacing: 0.08–0.12em`), лёгкое начертание (300), много свободного пространства вокруг.
- Короткие фразы 1–2 строки — самостоятельный визуальный элемент (hero, промо, пустые состояния).
- **Основной текст:** 400, комфортный интерлиньяж (~1.6), длина строки 60–75 знаков.
- Light (300) **не используется** для мелкого текста (< ~18px) — там 400: читаемость важнее формальной лёгкости.
- Кнопки, цены, категории, информационные акценты: Medium 500, коротко.

## 4. Логотип

- Версии: полная (знак + MON FLACON + дескриптор PERFUMES FOR EVERYONE) — ключевые точки контакта; **знак отдельно** (контур флакона) — favicon, компактная шапка при скролле, паттерн, мелкие форматы.
- Основная версия — на navy; инверсная — на cream/светлом.
- Охранное поле = высота буквы «M» в MON. Минимальный размер в вебе: полная версия не мельче ~120px ширины, меньше — только знак или знак + название.
- **Нельзя:** менять пропорции и толщину линий, тени/градиенты/обводки/эффекты, пёстрые фоны без контраста, цвета вне палитры.
- 📥 Запросить у дизайнера SVG-исходники (полный, знак, инверсии) + favicon-набор. Не перерисовывать.

## 5. Графический язык

- **Паттерн** из геометрии знака (дуги + вертикали): фоновая текстура с низким контрастом — hero, пустые состояния, страница «спасибо», упаковочные блоки. Тонко; никогда под текстом с потерей читаемости. 📥 запросить SVG.
- **Тонкие линии-разделители** (1px) организуют информацию — вместо теней, рамок и подложек.
- Композиция: центральная симметрия — лого и промо; аккуратная асимметрия — digital/editorial-страницы.
- **Воздух обязателен**: щедрые отступы, макеты не должны выглядеть заполненными.
- Формула промо-блока: **1 image + 1 phrase + logo.**
- Тени, градиенты, глянец — вне языка бренда. Ховеры и фокус — цветом и линией. Карточкам товара при необходимости — тонкий бордер, не elevation. Радиусы минимальные (0–4px): язык бренда — линия и геометрия, не «пилюли».

## 6. Фотостиль (= стайлгайд для 100+ фото каталога — передать клиенту)

- Свет: мягкий рассеянный, деликатные блики на стекле, длинные спокойные тени, **тёплая температура**.
- Фактуры: стекло, матовый камень, кремовая бумага, натуральная ткань, металл без сильного блеска.
- Тона: сине-серые, бежевые, молочные, дымчатые.
- Детали для editorial: макро, отражения, фрагменты рук, запястья, шеи, текстуры одежды.
- Для карточек каталога: единый светлый тёплый фон, флакон крупно, соотношение 1:1 или 4:5, ≥1200px по длинной стороне.
- **Избегать:** ярких пёстрых фонов, тяжёлой золотой эстетики, перегруженных композиций, жёсткого рекламного света, агрессивной ретуши, визуального шума.

## 7. Голос бренда (для UI-строк и текстов, все три локали)

- Характер: спокойный, внимательный, личный. Мягко, уверенно, конкретно, эстетично, без лишней сложности.
- **Не:** громко, снобистски, категорично, чрезмерно рекламно. Никаких «!!!», капс — только типографический (заголовки), не эмоциональный.
- Короткие фразы, чистая структура, точные описания нот и эмоций.
- Микрокопия: кнопка называет действие («Добавить в корзину»), давления нет.
- **Фирменные фразы остаются на английском во всех локалях** (элемент айдентики): *Find your signature.* · *A scent for every story.* · *Your scent. Your identity.* · *Scents that feel like you.* · дескриптор *Perfumes for everyone*.

## 8. Стартовые токены (сеются в `src/styles/tokens.css` в фазе 1)

```css
:root {
  /* MON FLACON — источник: docs/BRAND.md */
  --color-navy: #16293D;
  --color-cream: #E8CFB0;
  --color-surface: #FFFFFF;
  --color-surface-warm: #F6F0E4;   /* производный — уточнить по вайрфреймам */
  --color-ink: var(--color-navy);
  --color-ink-muted: #4A5A6B;      /* производный */
  --color-ink-on-dark: var(--color-cream);
  --color-line: #E3DACA;           /* производный: 1px разделители */
  --color-danger: #B3453C;         /* вне брендбука — согласовать */

  --font-sans: 'Inter', system-ui, sans-serif;  /* веб-замена Helvetica Neue, см. §3 */
  --tracking-display: 0.1em;
  --radius-sm: 2px;
  --radius-md: 4px;
}
```

## 9. Открытые запросы

1. 📥 SVG: логотип (полный + знак + инверсии), паттерн, favicon-набор — у дизайнера.
2. Решение по шрифту: Inter (бесплатно, дефолт) или покупка webfont Helvetica Neue — у клиента.
3. Цвет ошибок/статусов — согласовать (предложение в §2).
4. **Ожидается: структура и вайрфреймы страниц** — по ним финализируются распределение navy/светлых поверхностей и композиция (фаза 6).
